# 好老师升学帮 · 可视化升学说明书

在原 `haolaoshi-zsb` 项目中改造 `/about-haolaoshi`，沿用 Next.js 14、React 18 和 TypeScript。普通访客看到完整长页，咨询老师点击右上角「咨询讲解」后，进入 14 章节演示。原院校查询、6 位教师详情及历史数据仍保留。

## 运行

```bash
npm install
npm run dev
```

访问终端显示的本地地址加 `/about-haolaoshi`。当前本地预览为 `http://127.0.0.1:3000/about-haolaoshi`；根路径也会跳转至此。

生产检查：`npm run build`，完成后 `npm start`。
如需在开发服务运行时独立构建：`HLS_BUILD_DIR=.next-production npm run build`；对应运行命令为 `HLS_BUILD_DIR=.next-production npm start`。无需新增第三方 UI 依赖。

## 使用

- 普通浏览：14 章节长页，点击章节导航定位，当前章节自动高亮。
- 咨询讲解：右 / 下 / 空格下一章，左 / 上上一章，Esc 或底部按钮退出。退出恢复进入时的阅读位置。表单、标签和弹窗操作不会误翻章节。
- 图片：点击后在页内放大；支持左右按钮、方向键、手机滑动、细节放大、Esc 和背景关闭。恢复原阅读位置，不开新标签页。
- 原院校查询、教师详情与 PDF 在页内窗口打开。PDF 的显示由浏览器阅读器提供；窗口始终保留关闭按钮。
- 基础自测：英语 3 题 + 数学或语文 3 题；校验作答、给出结果与解析，可以将结果带入规划。
- 学习规划：按年级、类别、可投入时间、目标和基础生成；从当前年级起安排，不输出已经过去的学年；支持保存为 `.txt`。无需登录，不向服务器保存或发送自测结果。
- 手机和平板内容较长时可在当前章节内纵向滚动；电脑大屏优先采用一屏讲清一个问题的版式。

## 章节

全国布局 → 品牌实力 → 为什么升本 → 升学路径 → 浙江政策 → 专业查询 → 省控线 → 教学服务 → 核心师资 → 每日学习 → 三年规划 → 上课安排 → 集训住宿 → 我的下一步。

秋季课表、暑假文理科集训课表与六张住宿实拍在独立章节中直接展示，文字时间表、原图及说明无需打开弹窗即可阅读。图片仍支持连续放大查看。班型费用、状元班补充服务和学员反馈保留页内展开。

## 如何补充数据

### 学校与专业

在 `data/collegeMajorData.json` 增加学校对象，字段为 `id`、`name`、`short`、`page` 和 `majors`。当前 `page` 对应原表图片 `/promo/major-school-N.webp`；新增学校需同时准备对应原表图片。

每个专业包含：`id`、`major`、`baseMajor`、`categories`、`directions`、`notes`、`needsReview`。类别使用完整名称，如「理工类」「经管类」。`directions` 按类别保存本科专业名称数组。不要把尚未核对的对照关系填写成已确认可报；对照有差异时保留 `needsReview: true` 及说明。

当前专业名单和类别来自三校原表，本科方向引用原项目 2026 招生计划；先按类别与专科专业要求筛选，再优先展示相关方向，最多 4 个。它是资料范围内的参考入口，不是完整招生目录。院校的英语要求、具体专业限制等继续在「完整院校与本科专业查询」查看。

### 师资与成绩

编辑 `data/consultation.ts` 的 `faculty`；头像通过 CSS 从真实海报定位显示，`portrait` 控制位置，点击仍查看完整海报。未来有独立人像时可换成独立图片。2026 状元班 9 班明细与服务在 `data/promo.ts`。不同海报、班型、年份的样本不要相加或混用。

### 省控线

编辑 `data/consultation.ts` 的 `controlLines.years`、`rows[].values` 及 `sources`。每个类别的数值顺序必须与年份一致；图表和完整数据表自动更新。现有 2022–2026 数字均为已公布控制线，2026 不再标为预测。
